LAB-01 – C++ Programming

Course: Object-Oriented Programming with C++
Department: Artificial Intelligence
Stage: Second Year

Lab Description

This lab focuses on basic C++ programming concepts, including arrays, pointers, functions, and character arrays.

Tasks

Task 01 – Resize Array

Creating a new array with double size and copying the original elements along with their doubled values.

Task 02 – Diagonal Matrix

Checking whether a given square matrix is a diagonal matrix.

Task 03 – Character Array and Substring

Working with character arrays and extracting a substring based on the given length.

Programming Language

C++ (C++17)
