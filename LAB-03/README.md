LAB-03 – C++ Programming

Course: Object-Oriented Programming with C++
Department: Artificial Intelligence
Stage: Second Year

Lab Description

This lab focuses on structures, functions, arrays, and data processing using C++.

Tasks

Task 01 – Inventory System

Creating an inventory system to store item information, generate item codes, calculate selling prices, and display stock details.

Task 02 – Carpet Cost Calculator

Calculating carpet costs for multiple rooms using structures, functions, and dynamic memory allocation.

Programming Language

C++ (C++17)
